# Common Ground

An extension-owned Start tab. Reviewed software appears only for eligible recipients. Company mark first, creator on hover. Personal settings can always turn receiving off.

Start the local backend with `npm start` from the repository, install this VSIX, then run **Common Ground: Open Start**. Select a clearly labeled demo identity. The backend is loopback-only and uses local rehearsal identities; this is not production SSO.

The extension tracks workspaces opened while installed. It does not modify VS Code's native Recent history. Downloaded code is never executed automatically; workspace trust remains required.
